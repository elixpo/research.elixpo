# Security policy

## Reporting a vulnerability

Do not open a public issue for an unpatched vulnerability. Use GitHub's private
security-advisory form for `elixpo/research.elixpo` and include the affected
route, impact, reproduction steps, and any proposed mitigation.

Public content corrections, broken links, and inaccurate research metadata are
not security vulnerabilities; report those through the owning repository or
Elixpo Discussions.

## Supported scope

Security support covers the current `main` branch and the deployed static site.
Linked research code, models, data, and external demonstrations are governed by
their owning repositories.
